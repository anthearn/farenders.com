# Farenders

Static coming-soon website for https://farenders.com, hosted with GitHub Pages.

Uses the human-created Farenders logo and navigation card back. The repeating perspective background is rendered in CSS.

## Local preview

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765.

GitHub Pages serves the main branch from the repository root. The custom domain is set in CNAME; DNS must point farenders.com to GitHub Pages.
